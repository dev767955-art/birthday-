# Birthday Surprise Website 🎂

This is a simple, free birthday-surprise webpage.

## Customize
Open `index.html` and change:
- `Happy Birthday! 🎉`
- The birthday message
- The final message

You can also change the colors/appearance in `style.css`.

## Put it online for free
One simple option is GitHub Pages:
1. Create a GitHub account.
2. Create a new repository.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Enable GitHub Pages in the repository's Pages settings.
5. GitHub will give you a website link.
6. Turn that link into a QR code.

Note: GitHub Pages sites are public. Do not upload sensitive/private photos or other confidential information.
